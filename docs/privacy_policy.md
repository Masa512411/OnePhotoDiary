# プライバシーポリシー

One Photo Diary(以下「本アプリ」)における利用者の情報の取り扱いについて説明します。

## 1. 収集・送信する情報

本アプリは、利用者の情報を収集したり、開発者や第三者のサーバーに送信したりしません。

- 本アプリにはサーバーとの通信機能がありません。リリース版のアプリはインターネット接続の権限(Android の `INTERNET`)を要求しません。
- 利用状況の解析(アナリティクス)、クラッシュレポートの送信、広告は組み込んでいません。
- アカウント登録やログインはありません。

なお、設定画面の「プライバシーポリシー」をタップすると、このページが端末のブラウザで開きます。その際の通信はブラウザと GitHub との間で行われ、本アプリは関与しません。

## 2. 端末内に保存する情報

本アプリで記録した内容は、利用者の端末の中にのみ保存されます。

| 情報 | 保存先 |
| --- | --- |
| 日記の一言・日付 | 端末の安全な保存領域(iOS: キーチェーン / Android: 暗号化された SharedPreferences)。flutter_secure_storage を使用 |
| 撮影済みで日記に使っていない写真の一覧、リマインダーの設定 | 同上 |
| 写真 | 本アプリ専用の保存領域(他のアプリからは読めない領域) |

- 写真は保存時に JPEG に変換し、撮影場所(位置情報)などのメタデータ(EXIF)を取り除いています。アルバムから選んだ写真やバックアップから復元した写真も同様です。
- 日記を削除すると、その日の写真も本アプリの保存領域から削除されます(同じ写真を他の日の日記などで使っている場合は残します)。

### アンインストールしたとき

- **Android**: 本アプリをアンインストールすると、日記・写真・設定はすべて端末から削除されます。ただし、Google へのバックアップをオンにしている場合は、再インストール時にバックアップから写真などが復元されることがあります(「4. バックアップ」参照)。
- **iOS**: 写真は削除されます。日記の一言・日付などはキーチェーンに保存しているため、iOS の仕様によりアンインストール後も端末に残ることがあります。再インストール後の初回起動時に、残っていたデータが参照する写真が1枚も無い場合は、本アプリがそのデータを消去します。

## 3. 権限とその用途

| 権限 | 用途 |
| --- | --- |
| カメラ | 「今日の一枚」を撮影するため。Android では端末のカメラアプリを呼び出して撮影します(本アプリ自体はカメラの権限を要求しません) |
| 写真ライブラリ | アルバムから日記に使う写真を選ぶため。選んだ写真だけを読み込み、ライブラリ全体を読み取ることはありません。Android では OS の写真選択画面を使います |
| 通知 | 毎日の記録のリマインダーを通知するため。通知は端末内で予約するローカル通知で、外部のサーバーは使いません。端末の再起動後に予約し直すため、Android では起動完了の通知を受け取る権限も使います |
| 生体認証 / 画面ロック | アプリを開くときのロック解除のため。認証は OS が行い、本アプリが指紋や顔の情報を受け取ることはありません。Android では古い端末向けの指紋認証の権限も使います |
| バイブレーション(Android) | リマインダーの通知時に端末を振動させるため |

権限は端末の設定からいつでも取り消せます。取り消した場合、その権限を使う機能だけが使えなくなります。

## 4. バックアップ

### 本アプリの書き出し機能

設定画面の「書き出す」では、日記の一言・日付・写真を1つの zip ファイルにまとめ、共有シートで利用者が選んだ保存先(ファイル、クラウドストレージなど)に渡します。

- **書き出した zip ファイルは暗号化されていません。** ファイルを開ければ誰でも日記と写真を見られます。他の人に見られない保存先を選び、不要になったら削除してください。
- 保存先へ送る処理は、利用者が共有シートで選んだアプリやサービスが行います。その先での取り扱いは、それぞれのサービスの規約に従います。
- 書き出しのために端末内に一時的に作った zip ファイルは、一定時間(1時間)が経過した後、本アプリの起動時や設定画面を開いたときに削除します。復元のために選んだファイルのコピーも、復元が終わると削除します。

### OS のバックアップ機能

- **Android**: 本アプリは Android の自動バックアップを無効にしていません(`allowBackup` を指定しておらず、既定値の有効のままです)。利用者が端末で Google へのバックアップをオンにしている場合、本アプリの保存領域にある写真などが利用者の Google アカウントにバックアップされることがあります。日記の一言・日付は端末ごとの鍵で暗号化して保存しているため、別の端末に復元しても読み出せません。
- **iOS**: 本アプリの保存領域の写真は、iPhone の iCloud バックアップやコンピュータへのバックアップに含まれることがあります。日記の一言・日付などのキーチェーンのデータも、iCloud バックアップや暗号化したコンピュータへのバックアップに含まれ、そのバックアップから新しい端末に復元できます。

これらのバックアップは OS と利用者のアカウントの機能であり、開発者がその内容にアクセスすることはありません。
